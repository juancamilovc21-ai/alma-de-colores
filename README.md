# Alma de Colores 🎨🖌️🦉

Sitio web oficial de **Alma de Colores**: cerámicas, manualidades, empaques ecológicos y detalles hechos a mano con personalizador interactivo y asistente virtual.

## 🚀 Tecnologías utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Diseño responsivo y estilos personalizados.
- **JavaScript (Vanilla)**: Lógica interactiva del personalizador y asistente virtual.
- **Font Awesome**: Iconografía.
- **SweetAlert2**: Notificaciones interactivas.

## 🌐 Despliegue
Este proyecto está preparado para desplegarse fácilmente en **Vercel** o **GitHub Pages**.
